# Artwork and attribution

The four character PNGs in `assets/` are AI-generated project artwork created with OpenAI image generation for this application. The idle image is the user-approved baseline; typing, microphone and guitar poses were edited from that baseline so the same character, proportions, palette and outfit remain recognizable. Reference images supplied by the user were used only to communicate the ideas “cute keyboard companion” and “music pose”; their pixels were not bundled or copied into the app.

Files:

- `skirk-pet.png`: approved idle baseline; do not alter without explicit user approval.
- `skirk-typing.png`: temporary keyboard pose.
- `skirk-microphone.png`: temporary speaking/singing pose.
- `skirk-music.png`: temporary guitar pose.

Generation direction: transparent-background chibi desktop-pet sprite, consistent silver/lavender/ice-blue character identity, same costume and proportions as the approved baseline; change only the activity pose/prop. The activity images were regenerated when necessary to ensure a real alpha channel rather than a baked checkerboard or black background.
